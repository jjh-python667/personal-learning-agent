学习搭子

      
同学用管理员发来的链接进入。管理员用户名是 admin，密码是服务器上的网页密码，不要发到群里。

      

      

      

        
        
        
        
        
      

      

        
        
        
        
        
        
      

      

        
管理员怎么邀请

        
    
          
  1. 用 admin 和网页密码登录。
    2. 
          
  2. 打开「邀请同学」，填几天后过期、能用几次，生成链接。
    3. 
          
  3. 把链接发给同学。链接以 https:// 开头才适合在网上传。
    4. 
          
  4. 不想让人再用，点「收回」。收回或过期后，已经进来的同学也会退出。
    5. 
        

        
同学怎么试用

        
    
          
  1. 打开链接，自己起用户名和密码。
    2. 
          
  2. 选「体验示例」或「上传自己的资料」。
    3. 
          
  3. 跟着页面上的「问 → 分条 → 学 → 答 → 继续」走一遍。
    4. 
          
  4. 用完点右上角「退出」。
    5. 
        

      

    
    
      
第一次来，先选一种开始方式

      
「体验示例」会放进两份短笔记，跟着问、分条、学、答、继续走一遍。「上传自己」就用你的资料。
