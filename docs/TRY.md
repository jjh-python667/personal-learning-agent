# 怎么试用（大白话）

这一页给第一次用的人。管理员和同学看的不是同一段。

程序可以挂在 HTTPS 后面。自己电脑上先用 `http://127.0.0.1:8000` 试。发给同学的链接要是 `https://` 开头，配置见 [部署说明](DEPLOYMENT.md)。

## 管理员：发一个邀请

1. 打开网页。用户名填 `admin`，密码是服务器 `.env` 里的 `APP_PASSWORD`。这个密码不要发到群里，也不要贴到聊天记录里。
2. 左边点「邀请同学」。
3. 填两件事：几小时后过期、最多几个人能用。然后点「生成链接」。
4. 复制链接发给同学。正常样子是 `https://你的域名/invite#一串字符`。`#` 后面那串是邀请码。
5. 不想让人再用：点这张邀请的「收回」。过期了也会自动不能用。收回或过期之后，已经用这张邀请进来的同学，下次一点页面就会退出，需要再要一张新链接。

同学的账号和你的资料是分开的。QQ 机器人还是只听你自己（`.env` 里的 `QQ_OWNER_OPENID`），同学只能用网页。

## 同学：从链接走进来

1. 用手机或电脑打开管理员发来的链接。地址应是 `https://` 开头。
2. 给自己起一个用户名，设一个至少 8 位的密码，点「注册并进入」。密码自己记住，管理员看不到明文。
3. 第一次会问你怎么开始：
   - **体验示例**：放进两份短笔记，跟着页面走一遍。
   - **上传自己**：用你有权使用的 PDF、Word（.docx）、TXT 或 Markdown。
4. 跟着聊天页上的五步走：**问 → 分条 → 学 → 答 → 继续**。
   - 问：发一个具体问题，例如「示例里说的循环是什么？」
   - 分条：搭子会连着回你两三条，每条是一个气泡。
   - 学：点「开始连学」，或发送「带我学完编号1的资料，每次两页，开启连学」。
   - 答：看到题目后发送「答：你的答案」。
   - 继续：再发「继续」。
5. 用完点右上角「退出」。下次用用户名和密码登录，不用再要邀请，除非邀请已经过期或被收回。

## 失败了看哪一句

- 「还没有配置 DeepSeek」：可以先看资料。提问要等管理员在服务器配好密钥并重启。你不需要拿到密钥。
- 「今天的智能提问次数已经用完了」：等到明天，或请管理员把每天的额度调高。
- 「发送太快了」或「同时提问的人有点多」：歇几秒再发，不要连点。
- 「这个文件太大了」：换小一点的文件。扫描件、加密 PDF、旧版 `.doc` 也会失败，页面会说明原因。
- 「邀请已经过期或被收回」：向管理员再要一个新链接，然后重新注册或登录。

## 管理员可调的限额

写在服务器的 `.env` 里，改完重启网页服务。不要把填好的 `.env` 提交到仓库。

| 变量 | 意思 | 示例里的默认 |
| --- | --- | --- |
| `AI_DAILY_QUOTA` | 每个人每天几次智能提问 | 40 |
| `AI_MIN_INTERVAL_SECONDS` | 同一个人两次提问至少隔几秒，0 表示不限制 | 3 |
| `AI_MAX_CONCURRENCY` | 所有人加起来同时几个 | 2 |
| `AI_USER_CONCURRENCY` | 一个人同时几个 | 1 |
| `MAX_UPLOAD_BYTES` | 单个上传文件多大 | 12582912（12MB） |

对话、网页答题、继续任务各算一次。只是「列出资料」不算。次数记在数据库里，重启还在。间隔和「同时几个」记在内存里，重启会清掉这一小段间隔，当天次数不会清。
