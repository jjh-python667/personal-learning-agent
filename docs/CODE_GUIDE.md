# 从哪里开始读代码

我把项目分成几个文件，是为了能顺着一次请求理解整个过程。可以先看 `main.py` 的 `/api/chat`，再看 `agent.py` 的 `chat()`，最后看数据库保存在哪里。

## 三个容易混淆的概念

- 模型：负责理解文字、生成讲解或建议调用工具，不会直接连接我们的数据库。
- 工具：普通 Python 函数。先检查参数，再读取或保存数据，执行结果才交回模型。
- 状态机：用几个固定状态表示学习任务，程序根据结果改变状态，不靠模型随口说“完成”。

## 一次学习任务怎么走

用户发来开始学习的请求后，`lesson.py` 保存任务，按游标选出一块内容。讲解和出题成功后才更新已覆盖位置，并等待回答。答题成功后任务变回进行中；用户再发“继续”才处理下一块。最后一块答完后标记完成。暂停保留位置。

`cursor_page` 是下一块开始的位置，`covered_through` 是已经处理到的位置。Word 也沿用字段名，但含义是片段编号，不是真实页码。

## 为什么要记录步骤

模型请求可能超时。每块的读取、讲解、出题都有步骤编号；成功结果可以复用，失败后重试不会直接再插入同一个结果。答案与任务更新放在一个数据库事务里：一起成功，或者一起撤销。
